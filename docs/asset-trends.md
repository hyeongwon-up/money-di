# 순자산 추이 및 자산별 변화

기간: 최근 30일/90일/365일/전체. 요청 시작일 이하의 마지막 총액 기록을 기준으로 현재 전체 순자산과 비교한다. 이전 기록이 없으면 기간 안 첫 기록을 사용하고 실제 비교일을 표시한다. 같은 날짜의 여러 총액 기록은 가장 큰 ID를 사용한다. 미래 기록은 제외한다.

증감액 = 현재 순자산 − 기준 기록. 기준 순자산이 양수일 때만 변화율을 계산한다. 입출금/신규등록/삭제/수동 총액 수정/환율 영향이 섞인 순자산 변화이며 투자 수익률이 아니다. 부동산·부채를 현재값으로 과거에서 차감하던 추정 로직은 제거했다. 현재 요약/비중 필터는 추이의 전체 기준과 별도다.

개별 변화는 GET /api/assets/item-history의 기존 AssetItemHistory를 사용한다. 총액 기준일 이하의 마지막 개별 기록을 현재 원화 평가액과 비교한다. 일자·ID 순으로 마지막 기록을 선택한다. 해당 기록이 없으면 변화액/변화율을 만들지 않는다. 현재 보유 자산만 표시하며, 총액 변화와 비교 가능한 개별 변화의 합계 차이를 별도 안내한다. 부채 감소는 순자산 증가로 표시하고 음수 기준의 변화율은 생략한다.

향후 자산 저장/삭제 시에는 전체 순자산 및 보유 중인 모든 자산의 평가액을 같은 값들로 기록한다. 과거 이력을 소급 생성하지 않는다. 기록이 없는 날은 자동 일별 잔액이 아니며 그래프는 저장 기록 사이를 연결한다. Render 상시 실행이나 스케줄러에 의존하지 않는다.

스키마 변경 없음. 백엔드를 먼저 배포한다. 개별 이력 API가 실패하면 전체 추이만 제공하고 개별 비교는 명시적으로 오류를 표시한다. 기존 총액 수정 기능은 그래프 점 클릭 대신 '계산 기준 및 저장 기록 보기' 안의 수정 버튼으로 제공한다.
